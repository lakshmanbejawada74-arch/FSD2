In a university environment, hundreds of maintenance and operational service requests arise daily—ranging from classroom electrical faults, projector failures, and network switch outages to plumbing leaks, carpentry repairs, and laboratory equipment servicing. P[252][align=None][style=Normal]: CampusFlow: Smart Service & Issue Management System demonstrates how a robust, database-driven, enterprise web application can be built entirely with pure Java EE technologies without external third-party frameworks. Students can register, submit campus service requests, receive unique tracking numbers, monitor ticket progress through an audit timeline, and submit post-resolution feedback. Staff members manage assigned queues and log resolution remarks, while administrators govern user accounts, manage departments, dispatch technicians, and inspect live operational analytics. All application records are securely persisted in an Oracle 10g Express Edition database accessed through parameterized JDBC PreparedStatements, and web pages are dynamically rendered by JSP templates on Apache Tomcat 9. Security is woven throughout the application design: passwords use salted PBKDF2 key derivation, forms enforce anti-CSRF tokens, dynamic output is HTML-escaped, and sessions are guarded against fixation.
